# Sandeep Kumar Patel | Portfolio

Personal portfolio website for **Sandeep Kumar Patel**, a Technical Lead – Cloud & Infrastructure with 8+ years of IT experience, including 5+ years as a DevOps Engineer.

## 🌐 Live Site

[https://skpatel-88.github.io/skpatel-portfolio/](https://skpatel-88.github.io/skpatel-portfolio/)

A static, single-page portfolio showcasing experience, skills, and projects related to DevOps and cloud infrastructure.

## 📁 Project Structure

```
404.html          # Custom 404 error page
index.html        # Main portfolio page
script.js         # Site interactivity (banner slider, animations, etc.)
style.css         # Site styling
robots.txt        # Search engine crawling rules
sitemap.xml        # Sitemap for SEO
assets/
  images/         # Photos used in the banner and about sections
  logos/          # Company/tech logos
```

## ✨ Features

- Responsive, single-page layout
- Image banner/slider with navigation controls
- About, Skills, and Experience sections
- SEO basics (`robots.txt`, `sitemap.xml`)
- Custom 404 page

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
